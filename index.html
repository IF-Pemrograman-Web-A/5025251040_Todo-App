[E01a] The Style Warrior
Anda adalah seorang Style Warrior. Buatlah antarmuka pengguna (UI) statis dengan tata letak yang jelas dan responsif hanya menggunakan HTML dan CSS!
Tugas Anda adalah membuat halaman web Daftar Tugas (Todo List) dengan kriteria berikut:

  • 1. Buat halaman menggunakan elemen semantik HTML (header, main, aside, dan footer)
  • 2. Bagi konten menjadi dua panel: panel kiri untuk daftar tugas dan panel kanan untuk editor/detail tugas. Wajib menggunakan Flexbox atau Grid
  • 3. Buat komponen formulir terpisah untuk menambahkan tugas baru
  • 4. Gunakan daftar tugas statis dengan data dummy
  • 5. Antarmuka pengguna harus responsif, baik untuk tampilan desktop maupun seluler
  • 6. Gunakan gaya (style) eksternal

Output: file index.html dan style.css
